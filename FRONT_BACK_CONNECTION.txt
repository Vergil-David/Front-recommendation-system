FRONTEND-BACKEND CONNECTION NOTES

What was connected
- Frontend API client now has a safe fallback base URL:
  - Uses VITE_API_URL if provided
  - Falls back to /api if VITE_API_URL is not set
- Vite dev server proxy was added:
  - /api/* -> http://localhost:8080/*
  - This avoids browser CORS issues in local development

Important
- Go backend code was NOT changed.

How to run
1) Start backend (Go project) on port 8080.
2) In frontend project run:
   npm install
   npm run dev
3) Open frontend in browser.

Environment options
- Option A (recommended with proxy):
  - Set VITE_API_URL=/api (or leave it unset)
  - Frontend will call /api and Vite will proxy to backend

- Option B (direct backend URL):
  - Set VITE_API_URL=http://localhost:8080
  - Note: this can require CORS support on backend

API endpoints used by frontend
- POST /auth/register
- POST /auth/login
- GET /users/me
- GET /friends
- POST /friends/requests
- POST /friends/requests/respond
- GET /ping
